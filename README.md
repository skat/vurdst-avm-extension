# DK

Dette repository indeholder en forenklet og videreudviklet version af Vurderingsstyrelsens nuværende ejendoms- og grundværdimodeller. Forenklingerne omfatter både konstruktionen af datagrundlaget og den statistiske model med henblik på at skabe en transparent og reproducerbar analyse.

## Workflow

Projektet består af tre trin:

1. *load_data.R*
   - Henter og behandler de rå data leveret til Vurderingsstyrelsen.
   - Genererer tre datasæt:
     - vurderingsejendomme.rds
     - ejendomssalg.rds
     - grundsalg.rds

2. *Datasets.Rmd*
   - Indlæser de tre ovenstående datasæt.
   - Udvælger standard enfamiliehuse, ejendomssalg og grundsalg.
   - Renser data og omdøber variable.
   - Genererer det endelige analysesæt:
     - dataset.rds

3. *Analysis.Rmd*
   - Indlæser dataset.rds.
   - Fitter de statistiske modeller.
   - Indeholder analyser af modelkvalitet, performance og resultater.

## Datasæt

- *vurderingsejendomme.rds*
  - Danske vurderingsejendomme pr. 1. januar 2024.

- *ejendomssalg.rds*
  - Danske ejendomssalg fra 1. januar 2014 til 1. januar 2024.

- *grundsalg.rds*
  - Danske grundsalg fra 1. januar 2014 til 1. januar 2024.

- *dataset.rds*
  - Det endelige analysesæt med af ejendomme, ejendomssalg og grundsalg inden for parcelhuskategorien. Dannes af Datasets.Rmd.

De fire `.rds`-filer er inkluderet i repositoryet, så hele dataforberedelsen kan springes over, hvis man blot ønsker at reproducere analyserne.

## Øvrige filer

- *coordinates_ocean_land.csv*
  - Koordinatgrid over Danmark, som anvendes til at afgøre, om koordinater ligger på land eller hav.

- *prepare_figures.R*
  - Simpelt R-script til at generere figurer anvendt i rapporter, publikationer og præsentationer.

# EN

This repository contains a simplified and extended version of the Danish Public Valuation Agency's (Vurderingsstyrelsen's) current property valuation model. The simplifications concern both the construction of the underlying dataset and the statistical model, with the aim of providing a transparent and reproducible analysis.

## Workflow

The project consists of three steps:

1. *load_data.R*
   - Loads and processes the raw pre-model datasets delivered to the Danish Public Valuation Agency.
   - Produces three datasets:
     - vurderingsejendomme.rds
     - ejendomssalg.rds
     - grundsalg.rds

2. *Datasets.Rmd*
   - Loads the three datasets above.
   - Selects standard single-family properties, property sales, and lot sales.
   - Cleans the data and renames variables.
   - Produces the final analysis dataset:
     - dataset.rds

3. *Analysis.Rmd*
   - Loads dataset.rds.
   - Fits the statistical models.
   - Contains analyses of model quality, predictive performance, and results.

## Datasets

- *vurderingsejendomme.rds*
  - Danish properties as of 1 January 2024.

- *ejendomssalg.rds*
  - Danish property sales from 1 January 2014 to 1 January 2024.

- *grundsalg.rds*
  - Danish lot sales from 1 January 2014 to 1 January 2024.

- *dataset.rds*
  - Final analysis dataset containing single-family properties, property sales, and lot sales. Generated by Datasets.Rmd.

The four .rds files are included in the repository so that users can skip the data preparation steps and run the statistical analyses directly.

## Other files

- *coordinates_ocean_land.csv*
  - Coordinate grid covering Denmark used to determine whether locations fall on land or sea.

- *prepare_figures.R*
  - Simple R script for generating figures used in publications, documentation, and presentations.
